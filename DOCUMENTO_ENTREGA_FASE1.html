2. OBJETIVO GERAL E METAS ESPECÍFICAS (AULAS 1 A 5)

2.1. Objetivo Geral

O objetivo geral da Fase 1 consiste no desenvolvimento da estrutura front-end do sistema de comércio eletrônico e agendamento de serviços do Pet Amigo Petshop. O projeto foi projetado com estrita observância das normas do W3C e das orientações acadêmicas da disciplina, empregando exclusivamente HTML5 semântico puro, sem qualquer arquivo, tag ou atributo de estilização CSS/Bootstrap e sem scripts dinâmicos em JavaScript.

2.2. Metas Específicas e Articulação Pedagógica com as Aulas 1 a 5

  • Meta 1 – Estrutura Fundamental do Documento Web (Aula 1): Implementar documentos HTML válidos estruturados a partir da declaração <!DOCTYPE html>, especificação de idioma lang="pt-BR", codificação de caracteres charset="UTF-8" e meta tag viewport, garantindo a adequada renderização e arquitetura cliente-servidor em navegadores modernos e na plataforma GitHub Pages.
  • Meta 2 – Hierarquia Textual e Formatação Semântica (Aula 2): Estruturar os textos por meio de uma hierarquia lógica de cabeçalhos (<h1> a <h4>) sem saltos estruturais, utilização de parágrafos (<p>), divisores contextuais (<hr>), marcação de ênfase (<strong>, <em>) e informações de contato com <address>.
  • Meta 3 – Navegação, Hiperlinks e Listas (Aula 3): Conectar as páginas do sistema através de menus de navegação (<nav>) formados por listas não ordenadas (<ul> e <li>) e hiperlinks relativos (<a href="...">). Incorporar âncoras internas para salto de seções e listas de definição (<dl>, <dt>, <dd>) para termos técnicos e perguntas frequentes (FAQ).
  • Meta 4 – Inserção de Mídias e Modelagem de Tabelas de Dados (Aula 4): Integrar ilustrações vetoriais locais (SVG) com <figure>, <figcaption> e textos alternativos acessíveis (alt) em <img>. Desenvolver tabelas de dados complexas para exibição dos produtos e preços dos serviços utilizando <table>, <caption>, <thead>, <tbody>, <tfoot>, <th scope="col/row"> e mesclagem com rowspan.
  • Meta 5 – Estruturação Semântica HTML5 e Formulários Web (Aula 5): Segmentar as páginas utilizando os elementos estruturais do HTML5: <header>, <nav>, <main>, <section>, <article> e <footer>. Criar um formulário semântico e acessível de pré-agendamento de banho e tosa composto por <form>, <fieldset>, <legend>, <label for="...">, campos tipados (text, tel, email, number, date, radio, checkbox, select, textarea) e botões de submissão e limpeza.

3. ARQUITETURA DO SISTEMA WEB IMPLEMENTADO

3.1. Cabeçalho Padronizado (<header>)

Presente em todas as páginas, congregando a identidade corporativa do Petshop, logotipo oficial, título principal h1, horários de atendimento da loja e barra de navegação com links para todas as páginas da plataforma.

3.2. Corpo das Páginas (<body> / <main>)

O sistema foi concebido de forma modular e integrada por meio de 4 páginas:

  • Página Inicial (index.html): Apresenta a empresa, destaca 2 produtos de cada categoria (com fotos, especificações e preços) e resume os serviços de banho e tosa com/sem tele-busca e tabela de horários semanais.
  • Catálogo Completo de Produtos (produtos.html): Detalha a totalidade dos produtos divididos nas 3 categorias obrigatórias (apresentando 3 produtos por categoria, superando o requisito mínimo de 2 produtos), além de uma tabela consolidada de preços e códigos SKU.
  • Serviços e Agendamento (servicos.html): Detalha o funcionamento do centro estético animal, logística da tele-busca (leva e traz), tabela completa de valores por porte animal e formulário semântico de reserva.
  • Central de Ajuda e Manual (ajuda.html): Documentação de apoio ao usuário descrevendo o propósito do sistema, regras de navegação, formulário, conformidade W3C e FAQ.

3.3. Rodapé Padronizado (<footer>)

Contém informações de contato físico e digital (endereço, telefones, e-mail), mapa do site secundário, identificação acadêmica do estudante (PUCRS Online - Fundamentos WEB) e declaração de direitos autorais.

7. PROCEDIMENTO DE PUBLICAÇÃO NO GITHUB PAGES

Para hospedar a plataforma na nuvem via GitHub Pages, foram executados os seguintes passos:

1. Inicialização e commit no repositório local: cd petshop-web git init git add . git commit -m "feat: entrega Fase 1 do Projeto Petshop - Fundamentos WEB (PUCRS Online)" git branch -M main 2. Vinculação remota e envio para o GitHub: git remote add origin https://github.com/SEU_USUARIO/petshop-web.git git push -u origin main 3. Configuração do GitHub Pages no repositório: - Acessar "Settings" -> menu lateral "Pages" - Em "Build and deployment" -> "Source", selecionar "Deploy from a branch" - Escolher Branch: "main" e pasta "/ (root)" -> clicar em "Save" - O site estará acessível em: https://SEU_USUARIO.github.io/petshop-web/
